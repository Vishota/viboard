## Открыто

**A1. Публикация npm и публичная история.** [РЕШЕНИЕ]
В истории репозитория остались тестовые карточки, вложение и переписка из `board/`. Делать репозиторий публичным как есть нельзя: нужна чистая история (новая ветка без прошлого либо новый репозиторий). Публиковать пакет — после первого живого цикла на настоящей доске.

**A2. Первый коммит доски.** [СВЕДЕНИЕ]
`~/.viboard/board` — git-репозиторий без единого коммита; по протоколу его делает менеджер на проходе. До этого удаление карточки неотменимо.

**A3. Локальная папка репозитория.** [РЕШЕНИЕ]
Каталог называется `E:\proj\tasks`, репозиторий — уже `viboard`. Сессия не переименовывала каталог, в котором работает. Если переименуешь — поправь `path` проекта `viboard` в `~/.viboard/board/projects.yml`.

**A4. `npx vitask` как алиас.** [РЕШЕНИЕ — при публикации]
Установленная команда уже доступна под обоими именами (два `bin`). Для `npx vitask` без установки нужен второй, обёрточный пакет с именем `vitask`; тогда же стоит занять это имя в npm (N27).

**A5. Единый исполняемый файл без Node.** [ПОТОМ] Путь «без Node и без Docker» для аудитории UD-18; код к нему готов (сервер — модуль, интерфейс — статика).

**A6. Electron.** [ПОТОМ] UD-28.

**A7. Cookie другого локального приложения.** [СВЕДЕНИЕ]
На `127.0.0.1` страница доски видит в `document.cookie` cookie стороннего приложения (`auth:access`, `auth:refresh`): без HttpOnly и без изоляции по порту. Для viboard закрыто проверкой `Origin`. Не трогал — чужой проект; стоит проверить флаги cookie в back-auth.

**A8. Жест перетаскивания.** [СВЕДЕНИЕ] Автоматизация HTML5 drag and drop не инициирует; обработчик проверен настоящим `DragEvent`. Один раз проделать руками.
